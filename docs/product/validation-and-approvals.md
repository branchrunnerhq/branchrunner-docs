## Evidence states
Distinguish agent-reported results from independently validated checks and human-approved decisions. A completion statement is not a passing test.

## Validation
Run tests, type checks, linters, security tools, builds, and preview smoke tests inside the run workspace. Attach each result to the requirement it supports.

## Approval records
An approval records who decided, what transition was authorized, what evidence was visible, and when it occurred. Delivery should remain a separate decision from implementation completion.
