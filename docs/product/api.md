## Availability
The stable public API reference is not yet published. Do not build production automation against internal backoffice endpoints; they are deployment implementation details.

## Intended surface
The public API will cover task intake, run state, evidence retrieval, and approval requests. Authentication, versioning, pagination, and error shapes will be documented before the API is declared stable.

Use [webhooks](/docs/webhooks) for the event model and contact the team if an early integration depends on a specific endpoint.
