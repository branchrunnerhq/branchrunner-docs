# Describe the Claude subscription sign-in

The public pages no longer describe the Claude Code subscription path as on hold. On 2026-10-08
the owner enabled it through the official Claude Code CLI sign-in, based on Anthropic's
[Agent SDK and Claude plan article](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan).

**Changed**

- `agent-providers.md`: a Claude subscription account signs in through the official CLI from
  Integrations (sign-in link, then the code Claude shows); usage draws from the plan's limits; the
  installation owner turns on protected Claude execution first.
- `release-status.md`: the limitation now says the path is off until the owner selects it and
  still needs live acceptance.
