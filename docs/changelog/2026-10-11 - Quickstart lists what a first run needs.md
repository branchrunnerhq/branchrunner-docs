# Quickstart lists what a first run needs

## Fixed

- **Quickstart prerequisites.** The page no longer says one Codex or Claude
  subscription or API key is enough. A run needs coding agent access from two
  providers, because every change is reviewed as Critical and a Critical review
  needs a reviewer from a different provider and model family than the
  implementer. It also needs a human technical reviewer.

## Changed

- **Before your first run.** Replaces "Get to the first run" with the same 14
  steps as the **Get to your first run** checklist on Global Home: the second
  provider connection, a reviewer profile on it, the independent-review signing
  policy, the human reviewer qualification, credential enforcement and
  protected execution are now listed. It also notes the per-run credential
  approval that API-key runs need.
